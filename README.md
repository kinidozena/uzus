**[Открыть Узус](https://kinidozena.github.io/uzus/)**

Узус подбирает примеры грамматических конструкций английского языка из корпуса авторской прозы
(Project Gutenberg). В каталоге 94 конструкции в 12 разделах. У каждой группы разделов свой цвет:
герундий; инфинитив, сложное дополнение и сложное подлежащее; причастия; сослагательное наклонение
и условные предложения; видо-временные формы, пассив и модальные глаголы; придаточные предложения,
инверсия и выделение.

- 56 779 примеров из 246 книг; у каждого предложения автор, заглавие и ссылка на книгу.
- В предложении выделено слово, по которому правило узнало конструкцию.
- В каталог добавлены только конструкции, которые правила находят автоматически: при проверке
  чтением случайных примеров базы верны не меньше 9 из 10. Итоги проверки — в разделе
  «Как отобраны примеры».
- Отобранные предложения копируются нумерованным списком для задания; выделенное слово можно
  заменить пропуском.
- Свою книгу в формате .txt или .epub можно разметить тем же путём, что и корпус, когда работает
  сервер разметки; ход разметки виден под формой.

Прототип к научной статье по прикладной лингвистике. Страница работает в браузере; разметку своих
книг выполняет программа `server.py`, её адрес записан в файле `nastroyki.js`.
