**[Открыть Узус](https://kinidozena.github.io/uzus/)**

Узус подбирает примеры грамматических конструкций английского языка из корпуса авторской прозы
(Project Gutenberg). Восемь конструкций в четырёх группах, у каждой группы свой цвет:
герундий, причастные обороты, условные предложения и сослагательное наклонение, инфинитив цели.

- 14 197 примеров из 245 книг; у каждого предложения автор, заглавие и ссылка на книгу.
- В предложении выделено слово, по которому правило узнало конструкцию.
- Отобранные предложения копируются нумерованным списком для задания; выделенное слово можно
  заменить пропуском.
- Свою книгу в формате .txt или .epub можно разметить тем же путём, что и корпус, когда работает
  сервер разметки.

Прототип к научной статье по прикладной лингвистике. Страница работает в браузере; разметку своих
книг выполняет программа `server.py`, её адрес записан в файле `nastroyki.js`.
