# Сервис примеров из корпуса

Подбор примеров грамматических конструкций английского языка из корпуса авторской прозы
(Project Gutenberg). Прототип к научной статье по прикладной лингвистике; оформление Frutiger Metro.

Страница работает в браузере. Разметку своих книг (.txt, .epub) выполняет программа `server.py`;
её адрес записан в файле `nastroyki.js`.
